# Spine 目录预览器验收方案

状态：第一批实现已进行本地冒烟测试，见[本地测试记录](SPINE_VIEWER_LOCAL_TEST.md)。本表仍为完整验收计划，未逐项完成的用例保持「未执行」，不能用冒烟结果代替正式通过记录。

[设计方案](SPINE_VIEWER_DESIGN.md)

## 1. 验收规则

- P0：源文件安全、隔离、核心加载与生命周期；P1：约定版本能力、视觉正确性、必要交互；P2：体验优化。
- 交付范围内的 P0/P1 全部通过；失败与阻塞均不能视作通过。版本矩阵未覆盖的版本不得宣传支持。
- 第一批覆盖 3.8、4.0、4.1、4.2；3.6/3.7 是后续兼容目标，若要求宣称 3.6–4.2，必须把两者加入同等强度的必测矩阵。
- 每条记录结果（未执行/通过/失败/阻塞）、构建版本、样例 ID、实际结果、证据路径、问题编号、复测结果。
- 所有验证先在本地进行；通过本方案也不自动授权发布。

## 2. 环境、样例与基准

环境至少包括 Windows 10/11 x64、WebView2，100%/125%/150% 显示缩放，960×720 和 1440×900 窗口。一台干净机器不安装 Python、Node、Rust、Spine 编辑器、ImageMagick 或 TexturePacker；普通格式预览必须可用。记录 CPU、GPU、RAM、系统、WebView2、应用构建及 Runtime 精确版本。

每个约定版本族分别准备 JSON 与 SKEL，记录实际导出补丁版本，至少一个最小样例和一个复杂样例；SKEL 不能用 JSON 改后缀代替。样例来自有权使用的导出文件，不提交商业原素材。

| 样例组 | 内容 |
| --- | --- |
| D | 任意目录名、多层目录、中文/空格路径、不同目录同名骨架、混入普通 JSON |
| A | 同名 Atlas、共享 Atlas、多候选 Atlas、多页 Atlas、相对纹理路径、缺纹理、大小写不匹配 |
| V | 每版本 JSON/SKEL、缺版本、截断二进制、损坏 JSON、未来版本 |
| R | region、旋转/裁切、加权 mesh、deform、clipping、draw order、attachment 时间线 |
| C | IK、transform/path 约束，及版本适用的物理约束；多个动画、多个皮肤、无动画、空骨架 |
| T | PNG/JPG/WebP、透明边缘、PMA/straight alpha、加色/常规混合、多页不同 alpha 配置、Basis/KTX |
| L | 大目录、超大纹理、超大骨架、权限拒绝、符号链接/junction、越界 page、WebGL 上下文丢失 |

每份素材建立相对文件清单与 SHA-256。视觉基准使用对应版本的可信播放器或编辑器，在相同动画、皮肤、背景、PMA、视口、时刻下截图；保留运行时和参考播放器版本。优先检查时间 0、25%、50%、75% 和末尾，涉及关键帧边界的额外抽查。

## 3. 目录与安全

| ID | 级别 | 操作 | 预期 |
| --- | --- | --- | --- |
| DIR-01 | P0 | 选择 D 目录，拖放同一目录 | 两种方式均扫描，保留层级，找到相同骨架集合 |
| DIR-02 | P1 | 添加一组骨架/Atlas/纹理文件 | 形成资源集合；不要求目录叫 pc/mp/mobile |
| DIR-03 | P1 | 普通 JSON、同名骨架、搜索与筛选 | 普通 JSON 不误报；同名项有相对路径；筛选结果正确 |
| DIR-04 | P0 | 扫描中取消、改选目录、刷新 | 扫描可取消；旧结果不串入新目录；选择尽量保留 |
| DIR-05 | P1 | A 组自动/手动匹配 | 同名优先；歧义等待选择；共享/多页资源正确；缺页给出具体路径 |
| SAFE-01 | P0 | 导入、切换、播放、失败、取消后比较哈希 | 源清单和所有源文件哈希不变，不产生修改后的骨架或纹理 |
| SAFE-02 | P0 | Atlas 引用越界、绝对路径、网络地址、链接绕过 | 授权范围外读取被拒绝；补选授权目录后仅开放对应范围 |
| SAFE-03 | P0 | 素材名含 HTML/脚本内容 | 当文本显示，无脚本执行，不触发任意 Tauri 命令 |
| SAFE-04 | P0 | 断网、监控资源请求后播放 | Runtime 与素材从本地加载；素材内容不上传；外部链接仅用户点击打开 |

## 4. 版本与渲染

下表中 VER-01、REN-01/02/03 对每个交付版本的 JSON/SKEL 分别执行，不能只验证一个版本后批量打勾。版本不具备的特性可标不适用，但必须注明版本依据。

| ID | 级别 | 操作 | 预期 |
| --- | --- | --- | --- |
| VER-01 | P0 | 加载每个版本族 JSON/SKEL | 自动识别原始版本并选择匹配 Runtime；信息区同时显示两者；无需转换原文件 |
| VER-02 | P1 | 连续切换 3.8→4.2→4.0→4.1→3.8 | 无全局冲突、旧纹理或旧动画残留 |
| VER-03 | P1 | 未支持版本、缺版本、错误手动 Runtime | 明确不支持/识别失败/不匹配；不偷偷升级或显示成功 |
| REN-01 | P0 | 对照 R/C 组基准 | attachment、骨骼、mesh、裁切、绘制顺序及约束无结构性差异，无消失/错位 |
| REN-02 | P1 | 播放 T 组、多页 Atlas | 无漏页、旋转方向错误、白边/黑边、混合模式错误；PMA 切换符合基准 |
| REN-03 | P1 | 小特效、偏离原点、空动画、大范围运动 | 初次可见且合理居中；适应画布有效；不每帧缩放抖动；空 bounds 不崩溃 |
| REN-04 | P1 | Basis/KTX 等首期不支持纹理 | 明确提示格式不支持及建议，不误报 missing PNG 或加载成功 |
| REN-05 | P1 | 手动切换皮肤后拖动到多个时刻 | 插槽和 attachment 正确，无上一皮肤残留 |

视觉判定以可复现的参考对照为主，不要求不同 GPU 像素逐字节相同。轻微抗锯齿差异可记录；缺部件、错误位姿、遮挡关系、颜色或透明度明显错误一律失败。

## 5. 播放、交互与双语

| ID | 级别 | 操作 | 预期 |
| --- | --- | --- | --- |
| PLAY-01 | P1 | 播放/暂停/回到开头，循环开关 | 状态与时间一致；关闭循环到末尾停住；无动画可看 Setup Pose |
| PLAY-02 | P1 | 暂停状态切动画/皮肤 | 新动画从 0，保持暂停；皮肤按当前时间重建姿态 |
| PLAY-03 | P1 | 时间轴前拖、后拖，多次回到同一时刻 | 对应姿态可复现；拖动期间暂停，结束恢复原播放状态 |
| PLAY-04 | P1 | 物理约束样例从起点播放和 seek 对照 | 固定步进重放后姿态在约定容差内；不以只改 trackTime 代替 |
| PLAY-05 | P1 | 0.1/1/3 倍速播放，拖动后继续 | 动画时间比例正确；不会累积多个播放循环 |
| UI-01 | P1 | 缩放、平移、适应画布、重置 | 指针缩放稳定，按钮可恢复视图，时间轴操作不误拖画布 |
| UI-02 | P1 | 网格/原点/背景/PMA/调试开关 | 与画布即时一致；不支持能力不伪装为可用按钮 |
| UI-03 | P1 | 最小窗口及各显示缩放 | 主要操作可见或可滚动到达；属性抽屉可关；没有全页横向溢出 |
| UI-04 | P1 | 中英切换：空态、扫描、异常、播放中 | 控件、状态、提示均切换；动画名、文件名保持原文；不重载素材或丢失进度 |
| UI-05 | P1 | 键盘 Tab、空格、输入框输入 | 焦点可见；输入时不抢播放快捷键；按钮有可读名称 |

## 6. 稳定性、性能与原有功能回归

以下为拟定验收预算，技术验证时记录测试机及样例规模并冻结。未达到时记录失败及原因，不能在报告中省略测量条件。

| ID | 级别 | 操作 | 预期 |
| --- | --- | --- | --- |
| LIFE-01 | P0 | 快速连续选择 20 次不同资源 | 最后选择项获胜，失败实例释放，无旧资源覆盖 |
| LIFE-02 | P0 | 加载失败/取消后重新加载有效资源 | 可恢复，无白屏或永久 loading |
| LIFE-03 | P0 | 离开预览页、关闭窗口 | 离页暂停渲染，关闭释放；重新进入状态合理，无重复 RAF/事件监听 |
| LIFE-04 | P1 | 模拟 WebGL 不可用/丢失、超大纹理 | 明确错误和恢复操作；不崩溃、不无限重试 |
| PERF-01 | P1 | 本地 SSD：10,000 文件/1,000 骨架目录 | 扫描首批列表目标 2 秒内；扫描中可操作；取消目标 1 秒内响应；不预解码全部纹理 |
| PERF-02 | P1 | 单骨架≤200骨骼/5000顶点/2张2048纹理 | 本地冷加载目标 3 秒内；1080p 播放 60 秒，平均≥55 FPS、95%帧耗时≤33ms；记录测试 GPU |
| PERF-03 | P1 | 两资源反复切换100次，预热后取每20次稳定内存 | GPU纹理/实例数量不累积；末轮稳定内存不超过首轮20%且50MB余量中的较大值；说明采样/GC方法 |
| REG-01 | P0 | 预览同时有后台处理任务，来回切页面 | 处理不被暂停/取消；预览不改变任务选项或输出；资源被任务替换时合理报错/提示刷新 |
| REG-02 | P1 | 原 Spine/UI/视频流程、工具配置、链接跳转 | 原功能回归通过，新增预览不引入额外处理工具依赖 |
| PKG-01 | P0 | 干净 Windows 安装本地测试包，断网启动 | 所有宣称版本 Runtime 随包可用；普通纹理预览不要求开发环境或编辑器 |
| LIC-01 | P0 | 核对各版本 Runtime/解码器包 | 来源、锁定版本、许可条件和声明完整；不把第三方代码宣称为 MIT |

若版本实际需要不同采样重放精度或物理模拟时间，必须在适配器中记录，并把误差范围纳入该版本验收；不能用降低速度或禁用特性掩盖错误。
