# SpineSlim 2.0 Tauri 验收文档

状态：待实施、待执行。本文件是测试计划，不代表任何测试已经通过。

[升级方案](TAURI_UPGRADE_PLAN.md) · [返回首页](../README.md)

## 1. 验收范围与规则

验收 Windows x64 Tauri 迁移版，包括三种处理模式、配置、多语言、工具管理、任务生命周期及安装发布。Spine 查看器、macOS、多任务队列和自动更新不在本次范围内。

用例执行结果填写：未执行 / 通过 / 失败 / 阻塞。P0 为数据安全和核心运行项；P1 为功能与交互必需项；P2 为体验改进项。所有 P0/P1 必须通过才能正式发布；不适用项需有明确原因并经发布负责人确认，不能用“不适用”跳过核心功能。

## 2. 环境与样例准备

至少覆盖 Windows 10 x64、Windows 11 x64；其中一台为没有 Python、Node.js、Rust 的干净测试环境。构建机启动成功不能替代干净环境验收。

记录操作系统、显示缩放、CPU/RAM/GPU、WebView2、外部工具版本与许可状态。第三方工具缺失与安装完成两种状态都要测。素材使用可公开或内部有权测试的样例，不提交商业素材。

| 样例 | 内容 |
| --- | --- |
| S1 | 任意名称目录、两层子目录、中文/空格路径、JSON + Atlas + PNG |
| S2 | 已是 4.2、需升级的 JSON、不支持版本、无效 JSON、缺纹理 |
| S3 | 两个 Atlas 共用纹理、多页 Atlas、透明 PNG、已有 WebP/Basis |
| U1 | pce/pack 命名、普通 PNG/JPG/JPEG、尺寸边界、guide 文件 |
| U2 | winnum 艺术字、TTF/OTF、part JSON、视频混合输入 |
| V1 | 带音频视频、无音频视频、透明视频、奇数尺寸视频 |
| F1 | 缺工具、非零退出、worker 崩溃、只读输出、输出命名冲突 |
| C1 | 正常/损坏旧配置、未知字段、失效工具路径 |

对基线源文件记录相对路径、大小和 SHA-256，任务完成、失败和取消后重新比较。基线输出用同版本工具生成。PNG 无损结果按解码像素校验，JSON/Atlas 按结构和引用校验，有损图片与视频按格式、尺寸、透明度及视觉抽查验收，不要求压缩文件字节相同。

## 3. 后台、协议与目录安全

| ID | 级别 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| CORE-01 | P0 | 不启动 GUI，分别调用三个模式的 worker | 均可执行，不导入或依赖 Tkinter 控件 |
| CORE-02 | P0 | 发送非法参数和不支持的协议版本 | 明确拒绝，未清理输出、未启动处理工具 |
| CORE-03 | P1 | 分片发送 JSON 事件，混合连续多条事件 | 前端完整解析，中文与路径不乱码，顺序正确 |
| CORE-04 | P0 | worker 在处理中异常退出 | 任务变失败，界面恢复，不永久停留“处理中” |
| CORE-05 | P1 | 向新任务发送旧 task_id 事件 | 不污染当前进度或结果，每个任务仅一个终态 |
| SAFE-01 | P0 | 源目录等于或位于待清理输出目录内，三个模式分别验证 | 开始前拒绝，源文件与已有输出哈希不变 |
| SAFE-02 | P0 | 使用大小写路径、junction/符号链接指向源目录 | 识别实际目录关系，不能绕过保护 |
| SAFE-03 | P0 | 目标位于源目录内部且规则允许 | 跳过自己的输出，不递归重复复制；否则预检明确拒绝 |
| SAFE-04 | P0 | 分别执行成功、失败与取消 | 源目录清单和哈希不变 |
| SAFE-05 | P0 | 工具缺失或输入预检失败 | 不清理已有输出 |
| SAFE-06 | P0 | 只读目录、同名输出、工具生成空文件 | 清晰报错，不误报成功，不删除仍被引用的纹理 |
| SAFE-07 | P0 | 检查清理范围确认后启动 | 只清理已告知的目录，不影响其他模式保留目录 |

## 6. 任务生命周期

| ID | 级别 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| TASK-01 | P0 | 连续点击开始，处理中切换页面 | 最多一个任务，切页不重启或丢失任务 |
| TASK-02 | P1 | 任务启动后修改设置 | 当前任务使用启动时快照，下一任务使用新设置 |
| TASK-03 | P0 | 复制、图集和长视频处理中分别取消 | 立即显示取消中，停止后续派发，受控子进程结束，最终为已取消 |
| TASK-04 | P0 | 处理中关闭窗口，分别选择继续和退出 | 继续保留任务；确认退出后无残留 worker 或所属工具进程 |
| TASK-05 | P0 | 另开一个无关 FFmpeg 进程再取消本应用任务 | 无关进程不受影响 |
| TASK-06 | P1 | 长日志、错误、成功后再次运行 | 界面可响应，日志缓冲有上限，复制可用，新任务状态重置 |
| TASK-07 | P1 | 成功后打开输出目录、统计包体 | 打开正确位置；统计与实际文件总量一致 |

取消响应目标：1 秒内显示取消中，正常协作退出目标 10 秒内完成；超时终止策略需记录实际耗时，界面必须说明正在结束任务。性能目标须在记录硬件的条件下测量。
